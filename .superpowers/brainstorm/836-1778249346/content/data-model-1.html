数据模型（MVP）：哪些实体必须先落库？

基于：管理员/普通用户（你已确认）+ Excel 导入 + 评估 + 对比 + 报告

核心实体（建议）
  • User：用户（角色：admin/user）
  • Dataset：数据集（名称、描述、归属）
  • DatasetVersion：数据集版本（由一次上传产生，指向 Excel 文件与解析信息）
  • IngestJob：导入任务（解析/校验/入库日志）
  • RuleSet：指标规则集（版本化，管理员维护）
  • EvalJob：评估任务（输入：版本+规则集；输出：评估结果）
  • CompareJob：对比任务（输入：版本A/B；输出：差异结果）
  • Report：报告（引用某次评估/对比结果，可导出）
  • UserPreference：用户偏好（D3：记住上次A/B选择）
关系（简图）
User 1—N Dataset
Dataset 1—N DatasetVersion
DatasetVersion 1—N IngestJob
RuleSet 1—N EvalJob
DatasetVersion 1—N EvalJob
DatasetVersion(A/B) 1—N CompareJob
EvalJob / CompareJob 1—N Report
User 1—N UserPreference（last_compare_A/B per dataset）

结果明细（评估行级/差异行级）先按“文件导出 + 可查询摘要”做；后续再决定是否全量入库。
